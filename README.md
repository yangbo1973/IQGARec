# IQGARec
This is the pytorch implementation of our paper:
> IQGARec: Item-level Quantized Guidance and Augmentation for Diffusion-based Sequential Recommendation

## Requirements
This project is developed with the following environment:
- Python 3.10.11
- PyTorch 1.13.1 (CUDA 11.6)

```
torch==1.13.1+cu116
numpy==1.26.4
scikit-learn
```

## Train
```
python main.py
```
